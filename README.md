# SodaDLC — исходный проект

Полная исходная версия сайта SodaDLC v30 разложена на отдельные файлы.

## Структура
- `index.html` — опубликованная версия GitHub Pages.
- `src/index.html` — исходная HTML-разметка.
- `src/css/styles.css` — все стили сайта.
- `src/js/app.js` — JavaScript сайта.
- `data/README.md` — описание текущего хранения данных.

## Разработка
Для редактирования используйте папку `src`: HTML подключает `css/styles.css` и `js/app.js`. Корневой `index.html` оставлен для GitHub Pages и не менялся.

## База данных
В этой версии нет серверной БД. Регистрация хранится локально в браузере через localStorage; она не является общей для посетителей и не выгружается в GitHub. Подробности — в `data/README.md`.
