# Хранение данных SodaDLC

В исходном коде не найдено подключения к серверной базе данных (Firebase, Supabase, SQL или API базы).

- Аккаунты сохраняются в браузере через `localStorage` под ключом `sodadlc_accounts`.
- Сессия хранится в `sessionStorage`.
- У каждого посетителя своё локальное хранилище.
- GitHub Pages — статический хостинг, он сам по себе не сохраняет регистрации.

Здесь намеренно не добавлена фиктивная база данных: пустой JSON-файл не содержит пользователей и не восстановит их. Для общей базы нужно подключить backend/сервис базы данных и перевести регистрацию и авторизацию на сервер.
